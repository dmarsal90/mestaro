# Mestaro

Plataforma SaaS de gestión integral para restaurantes (POS, pedidos QR, KDS, inventario, pagos e informes).

Especificación: [docs/spec.md](docs/spec.md)

Arranque local: `make web && make up`. El gateway (`http://localhost:8100`) sirve la API, la app del personal y, en `/m/<token>`, la del comensal.
